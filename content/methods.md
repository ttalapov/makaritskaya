# Методы работы — исходный список

Источник для блока «Методы» на сайте. 26 пунктов. Порядок здесь — исходный,
группировка для вёрстки задана в ТЗ.

Пункты, помеченные `[®]`, содержат защищённые или сертифицируемые названия.
Решение по ним принято: полные названия **не публикуются**. Для №19 на сайте
остаётся только общая часть — «структурирование среды», без названия TEACCH.
Если обучение будет подтверждено документами, они вернутся.

Публикуется 22 позиции из 26.

1. **Ayres Sensory Integration® (ASI)** `[®]`
   Ключевой принцип ASI: не просто дать ребёнку сенсорный стимул, а организовать
   деятельность так, чтобы ребёнок сформировал адаптивный ответ
2. **Работа с вестибулярной системой**
   Стимуляция во всех проекциях вестибулярной системы
3. **Проприоцептивная терапия**
   Работа через мышцы, суставы и сопротивление
4. **Тактильная терапия**
   При тактильной защитности используется градуированное воздействие, а не принуждение
   ребёнка терпеть неприятный стимул
5. **Праксис и моторное планирование**
   Один из центральных компонентов сенсорной интеграции. Работа включает: Ideation →
   Motor planning → Execution. То есть: идея действия → планирование → выполнение
6. **Постуральная терапия**
   Работа над: тонусом, стабильностью корпуса, контролем головы, проксимальной
   стабильностью, равновесием, защитными реакциями, антигравитационными реакциями,
   удержание переходами между позам, координацией туловища и конечностей
7. **Билатеральная интеграция**
   Развитие согласованной работы двух половин тела
8. **Зрительно-моторная интеграция**
9. **Слуховая сенсорная обработка**
10. **Интероцептивная работа**
   Современная практика всё чаще учитывает интероцепцию — способность ощущать внутренние
   сигналы тела
11. **Сенсорная диета / Sensory Lifestyle**
   Это не отдельный «набор упражнений», а индивидуальная организация сенсорной среды и
   активности ребёнка в течение дня
12. **Сенсорная модуляция**
   Работа с гиперреактивностью, гипореактивностью, сенсорным поиском, колебаниями уровня
   возбуждения, трудностями перехода между состояниями
13. **Десенсибилизация**
   Используется при сенсорной защитности
14. **Сенсорная дискриминация**
   Развитие способности различать характеристики стимулов, а не просто их воспринимать
15. **Двигательно-координационная терапия**
16. **Ритмические методы**
   Особенно полезно сочетать ритм + движение + двустороннюю координацию
17. **Игровая терапия**
   В сенсорной работе игра является не просто развлечением, а способом организовать:
   мотивацию → движение → сенсорный опыт → адаптивный ответ
18. **DIR/Floortime** `[®]`
   Может использоваться как отдельный развивающий подход, особенно при работе с
   социально-коммуникативными трудностями
19. **TEACCH-подход и структурирование среды** `[® частично]`
20. **ABA/поведенческие методы** `[®]`
21. **NDT / Bobath** `[®]`
   Нейроразвивающий подход может использоваться специалистами при определённых
   двигательных нарушениях
22. **Подходы к развитию крупной моторики**
23. **Fine Motor / мелкая моторика**
